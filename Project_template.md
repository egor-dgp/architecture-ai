# RAG-бот для корпоративного AI-ассистента

## Описание проекта

Целью проекта является разработка полнофункционального RAG-бота (Retrieval-Augmented Generation), который демонстрирует использование современных техник работы с большими языковыми моделями, векторными базами данных и методов защиты от атак на промпты.

Проект состоит из пяти заданий, которые постепенно строят RAG-систему: от подготовки базы знаний до демонстрации работы с защитой от промпт-инъекций.

---

## Задание 1: Выбор архитектуры и инструментов

### Описание

В первом задании определены основные компоненты архитектуры RAG-системы и выбраны инструменты для каждого слоя.

### Выбранная архитектура

```
┌─────────────────────────────────────────────────────────────┐
│                    RAG-система                              │
├─────────────────────────────────────────────────────────────┤
│ 1. Knowledge Base (Подготовка данных)                       │
│    └─ Синтетическая база на основе Star Wars               │
│                                                              │
│ 2. Embedding & Indexing (Векторизация)                      │
│    ├─ Модель: sentence-transformers/all-MiniLM-L6-v2       │
│    └─ Индекс: ChromaDB (PersistentClient)                  │
│                                                              │
│ 3. Retrieval (Поиск)                                        │
│    └─ Semantic search по 384-мерным векторам               │
│                                                              │
│ 4. LLM (Генерация)                                          │
│    └─ Ollama (локально) или OpenAI API                     │
│                                                              │
│ 5. Security (Защита)                                        │
│    ├─ Pattern-based filtering                              │
│    ├─ System prompt hardening                              │
│    └─ Post-generation validation                           │
└─────────────────────────────────────────────────────────────┘
```

### Основные компоненты

| Компонент | Выбор | Обоснование |
|-----------|-------|-------------|
| **Языки/Framework** | Python 3.11, LangChain | Экосистема ML/NLP, простота интеграции |
| **Модель эмбеддингов** | sentence-transformers/all-MiniLM-L6-v2 | Легкая (83MB), 384-мерные вектора, хороший баланс скорость/качество |
| **Векторная БД** | ChromaDB | Простая, работает локально, встроенная поддержка embeddings |
| **LLM** | Ollama (Mistral) + OpenAI API | Локальное тестирование, опциональное облако |
| **Текст-сплиттер** | LangChain RecursiveCharacterTextSplitter | Умное разбиение на смысловые чанки |
| **Фреймворк API** | FastAPI (опционально) | Для REST endpoint |
| **Промптинг** | Few-shot + Chain-of-Thought | Улучшение качества ответов |

### Стек технологий
